# تطبيق مواقيت الصلاة لسطح المكتب — لغة جزائر (Djazair Prayer Times)

تطبيق سطح مكتب متكامل وفاخر لمواقيت الصلاة حسب الدول والمدن، مبني باستخدام **لغة البرمجة جزائر (Djazair)** وإطار عمل **WebView2 (Chromium)** عبر إضافة `webview`، ومحزّم كملف تنفيذي مستقل (`.exe`) عبر **`dpack`**.

---

## مميزات التطبيق

1. **دعم شامل لولايات الجزائر الـ 58 والعالم العربي والإسلامي:**
   - قائمة بجميع الولايات الجزائرية الـ 58 مع أسماء المدن بالعربية وإحداثياتها الدقيقة.
   - كبرى عواصم ومدن العالم العربي والإسلامي.
   - **التحديد التلقائي للموقع (Auto-Geolocation)** عبر الـ IP بضغطة زر.
2. **محرك مزدوج لجلب وحساب المواقيت (Online & Offline):**
   - **عبر الإنترنت (Online API):** جلب المواقيت بدقة عبر Aladhan API مع تتبع التحويلات التلقائي والتاريخ الهجري والميلادي.
   - **بدون إنترنت (Offline Fallback):** محرك حسابات فلكية شمسية محلي مدمج بلغة جزائر (`services/calculator.dz`) يعمل تلقائياً عند انقطاع الإنترنت.
3. **بوصلة اتجاه القبلة التفاعلية (Qibla Compass):**
   - حساب زاوية القبلة الدقيقة فلكياً من إحداثيات المدينة نحو الكعبة المشرفة مع بوصلة دائرية متحركة.
4. **قسم أذكار المسلم (Athkar):**
   - أذكار الصباح، أذكار المساء، وأذكار بعد الصلاة مع نصوص مضبوطة بالشكل وعداد تفاعلي لكل ذكر.
5. **السبحة الإلكترونية الرقمية (Digital Tasbeeh):**
   - سبحة دائرية تفاعلية مع نغمات نقر واهتزاز، أهداف قابلة للتخصيص، وإحصائيات إجمالي التسبيحات المحفوظة.
6. **وضع شهر رمضان المبارك (Ramadan Mode):**
   - عداد تنازلي خاص لوقت الإفطار (المغرب) ووقت الإمساك (الفجر).
   - أدعية الإفطار المأثورة وأدعية الشهر الفضيل.
7. **تخصيص أصوات الأذان والمؤذنين (Custom Adhan Voices):**
   - خيارات متعددة لأصوات الأذان مع إمكانية استعراض واختيار ملف صوتي مخصص (`.mp3` / `.wav`) من جهاز المستخدم.
8. **التكامل مع نظام ويندوز (Windows Integration):**
   - إشعارات سطح المكتب الرسمية (Windows Toast Notifications).
   - خيار التشغيل التلقائي مع إقلاع النظام (Launch on Startup).
   - خيار التصغير إلى شريط المهام (Minimize to Tray).
9. **برنامج تنفيذي مستقل (Standalone Executable):**
   - تم تحزيم التطبيق عبر أداة `dpack` ليعمل مباشرة كملف `prayer_times.exe` دون الحاجة لتثبيت أي متطلبات مسبقة.

## هيكل المشروع

```
prayer_times/
├── prayer_times.exe        # البرنامج التنفيذي المستقل الجاهز للتشغيل
├── main.dz                 # نقطة الدخول الرئيسية للبرنامج وربط WebView2 والجسر البرمجي
├── build_app.dz            # سكربت التحزيم وإنشاء ملف الـ EXE عبر dpack
├── run.bat                 # ملف تشغيل سريع للتطبيق على ويندوز
├── services/
│   ├── geo.dz             # قاعدة بيانات الدول والمدن الـ 58 وطرق الحساب
│   ├── storage.dz         # إدارة الإعدادات المحلية والتخزين المؤقت
│   ├── calculator.dz      # محرك الحسابات الفلكية الشمسي (Offline Fallback)
│   ├── api.dz             # خدمة جلب المواقيت وتحديد الموقع وحساب زاوية القبلة
│   └── athkar.dz          # قاعدة بيانات أذكار الصباح والمساء والسبحة وأدعية رمضان
├── ui/
│   ├── index.html         # هيكل الواجهة والتبويبات الأربعة
│   ├── style.css          # التصميم والأنماط البصرية الزجاجية الإسلامية
│   └── app.js             # محرك التفاعل والعدادات التنازلية والسبحة والأذان
└── data/                  # مجلد الحفظ التلقائي لـ settings.json و cache.json
```

## طريقة التشغيل

* **التشغيل المباشر كبرنامج مستقل (موصى به):**
  الضغط المزدوج على ملف:
  ```
  prayer_times/prayer_times.exe
  ```
* **أو عبر ملف Bat:**
  الضغط المزدوج على:
  ```
  prayer_times/run.bat
  ```
* **أو عبر سطر الأوامر (للمطورين):**
  ```powershell
  djazair.exe prayer_times/main.dz
  ```
