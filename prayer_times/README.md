## ✨ المميزات الرئيسية

### 1. 🇩🇿 دعم شامل لجميع الدول العربية الـ 22 وولايات الجزائر الـ 58
- تغطية رسمية ودقيقة لجميع **ولايات الجزائر الـ 58** بكافة مدنها وإحداثياتها الجغرافية.
- دعم كامل وشامل لجميع **الدول العربية الـ 22** بكافة عواصمها ومدنها الرئيسية (السعودية، فلسطين، مصر، المغرب، تونس، الإمارات، قطر، الكويت، عمان، البحرين، الأردن، العراق، اليمن، سوريا، لبنان، السودان، ليبيا، موريتانيا، الصومال، جيبوتي، جزر القمر)، بالإضافة لمدن الجاليات الإسلامية (تركيا، بريطانيا، فرنسا).
- **التحديد التلقائي للموقع (Auto-Geolocation):** كشف الدولة والمدينة الحالية بنقرة واحدة عبر الـ IP.

### 2. ⚡ محرك مزدوج لحساب المواقيت (Online & Offline Engine)
- **عبر الإنترنت (Online API):** مزامنة دقيقة مع خوادم Aladhan API مع تواريخ هجرية وميلادية دقيقة واستعلام بالإحداثيات الجغرافية المباشرة لتفادي أي أخطاء.
- **بدون إنترنت (Offline Astronomical Engine):** محرك حسابات فلكية شمسية محلي مدمج مكتوب بلغة جزائر (`services/calculator.dz`) يعمل تلقائياً وبكل دقة في حال انقطاع الاتصال بالإنترنت.
- **طرق حساب فلكية معتمدة لكل دولة:**
  - وزارة الشؤون الدينية والأوقاف الجزائرية (Method 19)
  - جامعة أم القرى - مكة المكرمة (Method 4)
  - رابطة العالم الإسلامي (Method 3)
  - الهيئة المصرية العامة للمساحة (Method 5)
  - رئاسة الشؤون الدينية التركية (Method 13)
  - جامعة العلوم الإسلامية بكراتشي (Method 1)
  - الجمعية الإسلامية لأمريكا الشمالية (ISNA Method 2)

### 3. 🔊 محرك صوتي متطور (Web Audio API Buffer Engine)
- **تشغيل فوري بـ 0 تأخير:** يعتمد على فك ترميز ملفات الـ MP3 في الذاكرة كـ PCM Buffers لتجاوز قيود تشغيل وسائط HTML5 في WebView2.
- **تخصيص صوت الأذان لكل صلاة:**
  - الأذان الجزائري الأصيل (بصوت المؤذن الجزائري حاج سليمان مختار رحمه الله).
  - أذان الحرم المكي الشريف.
  - أذان الحرم النبوي الشريف بالمدينة المنورة.
  - نغمة تنبيه رنانة هادئة (Synthetic Chime).
  - إمكانية استيراد **ملف أذان مخصص (`.mp3`)** من جهاز المستخدم.
- تحكم حي ومباشر في مستوى الصوت (Volume Slider) عبر `GainNode`.

### 4. 🪟 الوضع المصغر العائم (Mini Floating Widget)
- نافذة مصغرة عائمة ومثبتة دائماً فوق النوافذ (**Always-on-Top**).
- شريط معلومات أنيق يعرض: المدينة، الصلاة القادمة، وقتها، والعداد التنازلي الحي.
- أزرار سريعة للتحكم: تشغيل/إيقاف الأذان بنقرة واحدة، التكبير للواجهة الكاملة، أو التصغير لشريط المهام.
- دعم السحب والإفلات وتغيير الموقع بسلاسة تامة.

### 5. 🔔 تكامل متكامل مع نظام ويندوز (Windows Integration)
- **صينية شريط المهام (System Tray):**
  - تصغير سلس للبرنامج بجانب الساعة للعمل في الخلفية بأقل استهلاك للموارد.
  - **تلميح ديناميكي حي (Dynamic Tray Tooltip):** يظهر اسم الصلاة القادمة والوقت المتبقي عند تمرير مؤشر الفأرة فوق أيقونة التطبيق في شريط المهام.
  - إشعارات منبثقة أصلية (Balloon Notifications) مرتبطة بأيقونة التطبيق دون ترك أي أيقونات شبحية.
- **تنبيه ما قبل الأذان (Pre-Adhan Reminder):** تنبيه مبكر قبل دخول وقت الصلاة بـ 5 إلى 30 دقيقة للاستعداد والوضوء.
- **مواقيت الإقامة (Iqama Times):** حساب وعرض وقت إقامة الصلاة لكل فريضة مع تنبيه عند موعد الإقامة.
- **التشغيل التلقائي (Launch on Startup):** إدارة تسجيل الإقلاع مع ويندوز من داخل الإعدادات.

### 6. 📿 قسم أذكار المسلم والسبحة الإلكترونية
- **أذكار الصباح والمساء وأذكار ما بعد الصلاة:** نصوص قرآنية ونبوية مضبوطة بالشكل، مع عدادات تفاعلية، وتتبع نسبة إنجاز الأذكار.
- **تنبيهات أوقات الأذكار:** إشعار تلقائي بوقت أذكار الصباح بعد الفجر ووقت أذكار المساء بعد العصر.
- **السبحة الرقمية الذكية (Digital Tasbeeh):** عداد نقر دائري تفاعلي مع مؤثرات صوتية وبصرية، أهداف محددة (33، 100، أو حر)، وحفظ تلقائي لإجمالي التسبيحات.

### 7. 🌙 وضع شهر رمضان المبارك (Ramadan Mode)
- عداد تنازلي خاص لوقت الإفطار (المغرب) ووقت الإمساك (الفجر).
- أدعية الإفطار المأثورة وأدعية الصيام المباركة.

### 8. 🔕 الوضع الهادئ أثناء العمل / الألعاب (Do Not Disturb - DND)
- زر تبديل سريع بنقرة واحدة في الشريط العلوي (`#btnDnd`) لكتم الأذان الصوتي فوراً أثناء العمل المركز أو الألعاب أو الاجتماعات.
- كتم كافة الأصوات التلقائية مع الإبقاء على الإشعارات المرئية الخفيفة بجانب الساعة.

### 9. 🔍 مربع البحث السريع الفوري في المدن (Instant City Search Filter)
- حقل بحث فوري مدمج في شريط اختيار الموقع يدعم البحث بالعربية والإنجليزية ورقم الولاية/المدينة.
- فلترة حية وسريعة بين مدن وعواصم كافة الدول العربية والولايات الـ 58.

### 10. 🕌 تنبيهات يوم الجمعة والمناسبات الفضيلة وسنن الصيام
- **سورة الكهف والصلاة على النبي ﷺ:** تنبيه صباحي في نهار كل جمعة للتذكير بسنن اليوم المبارك.
- **ساعة الاستجابة:** تنبيه قبل ساعة واحدة من أذان المغرب يوم الجمعة لاغتنام وقت الدعاء المستجاب.
- **صيام النوافل والأيام البيض:** تنبيهات مسائية لصيام الإثنين والخميس، وصيام الأيام البيض (13، 14، 15 من كل شهر هجري).

### 11. 📿 شريط الذكر التلقائي الهادئ (Subtle Dhikr Ticker)
- بطاقة ذكر نبوي عائمة بتصميم زجاجي هادئ تظهر دورياً في أسفل الشاشة (كل 15، 30، أو 60 دقيقة).
- إمكانية نسخ الذكر فوراً بنقرة واحدة أو إغلاقه مع اختفاء تلقائي سلس بعد 10 ثوانٍ.

### 12. 💾 إدارة وحفظ الإعدادات في ملف JSON قياسي
- حفظ تلقائي لكافة الإعدادات والخيارات في ملف مقروء `settings.json`.
- زر مخصص لفتح مجلد الإعدادات في Windows Explorer مباشرة.

## 🏗️ هيكل المشروع وهندسة البرمجية

```
prayer_times/
├── salati.exe                  # الملف التنفيذي المستقل الجاهز للتشغيل مباشرة
├── main.dz                     # نقطة الانطلاق وإعداد النافذة والشريط ومحرك WebView2
├── build_app.dz                # سكربت تجميع وتحزيم التطبيق عبر أداة dpack
├── .gitignore                  # استبعاد الملفات المؤقتة والذاكرة المخبأة
├── README.md                   # التوثيق الشامل للتطبيق
├── core/
│   ├── config.dz              # الثوابت ومسارات المجلدات وإعدادات التطبيق
│   └── platform.dz            # تكامل ويندوز (الأيقونة، المسار، وسجل الإقلاع Registry)
├── bridge/
│   ├── ipc.dz                 # قنوات الاتصال الثنائي (IPC) بين لغة جزائر والواجهة
│   └── tray.dz                # إدارة صينية شريط المهام (Tray)، القائمة، والتلميحات
├── services/
│   ├── geo.dz                 # قاعدة بيانات ولايات الجزائر الـ 58 ومدن العالم
│   ├── api.dz                 # خدمة جلب المواقيت عبر الإنترنت وتحديد الموقع والقبلة
│   ├── calculator.dz          # محرك الحساب الفلكي الشمسي المحلي (Offline Fallback)
│   ├── athkar.dz              # قاعدة بيانات الأذكار النبوية وأدعية رمضان
│   └── storage.dz             # إدارة تخزين واسترجاع الإعدادات (JSON Storage)
├── data/                      # المجلد الدائم لحفظ settings.json
└── ui/                        # واجهة المستخدم الحديثة (Glassmorphism UI)
    ├── index.html             # هيكل الواجهة وتبويبات التطبيق ونوافذ الحوار
    ├── style.css              # الأنماط الجمالية الإسلامية وتنسيقات الوضعين العادي والمصغر
    ├── audio/                 # ملفات الأذان والتنبيهات الصوتية (.mp3)
    └── js/                    # بنية جافاسكريبت المعيارية
        ├── state.js           # مخزن الحالة المركزي (State Store)
        ├── elements.js        # كاش عناصر الـ DOM والمحددات
        ├── ipc.js             # وسيط التخاطب مع لغة جزائر (IPC Bridge)
        ├── audio.js           # محرك Web Audio API Buffer Engine للتشغيل الفوري
        ├── clock.js           # ساعات المواقيت، العدادات التنازلية، ومؤقتات الصلاة
        ├── settings.js        # منطق نافذة الإعدادات وتبويباتها
        ├── athkar.js          # منطق الأذكار وتتبع العدادات
        ├── tasbeeh.js         # السبحة الإلكترونية
        ├── ramadan.js         # وضع شهر رمضان
        └── app.js             # المنسق العام وبداية تشغيل الواجهة (App Orchestrator)
```

## 🛠️ التقنيات والمحركات المستخدمة

| التقنية / المكون | الوصف والاستخدام |
| :--- | :--- |
| **لغة البرمجة جزائر (Djazair)** | اللغة الأساسية التي تم بناء وبرمجة كافة وظائف التطبيق، الحسابات الفلكية، وخدمات النظام بها |
| **حزمة `webview` للغة جزائر** | إنشاء وإدارة نافذة سطح المكتب بدون إطار (Frameless)، شريط المهام، وقنوات الـ IPC |
| **Microsoft Edge WebView2** | محرك العرض الداخلي (Chromium Core) لتقديم أداء رسومي عالٍ واستهلاك خفيف للذاكرة |
| **أداة `dpack`** | أداة التحزيم الرسمية في لغة جزائر لضغط السكربتات ومكتبات C++ وإنشاء `salati.exe` المستقل |
| **Web Audio API** | محرك تشغيل ومعالجة الصوتيات بدقة PCM Buffer لمنع مشاكل تقطيع أو تأخير البث |
| **HTML5 & Modern CSS3** | تصميم زجاجي عصري (Glassmorphism) متجاوب مع دعم كامل للغة العربية (RTL) |

## 🚀 طريقة التشغيل والتثبيت

### 1. التشغيل المباشر كبرنامج مستقل (موصى به للمستخدم)
لا يتطلب تثبيت لغة جزائر أو أي برامج أو متطلبات مسبقة:
- قم بتشغيل البرنامج مباشرة بنقر مزدوج على:
  ```powershell
  salati.exe
  ```

### 2. التشغيل من الكود المصدري (للمطورين)
إذا كانت لغة جزائر مثبتة في بيئتك:
```powershell
cd prayer_times
djazair main.dz
```

## 📦 بناء التطبيق المستقل (Build with dpack)

لإعادة تجميع التطبيق وتوليد ملف `salati.exe` مجمّع ومحزّم بالكامل:

```powershell
djazair build_app.dz
```

سيقوم السكربت بفحص كافة التبعيات، ضغط الأصول البرمجية، ودمج مفسر لغة جزائر مع إضافات الـ C++ في ملف تنفيذي واحد بحجم ~6 ميغابايت فقط.
