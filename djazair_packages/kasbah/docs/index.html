Modern, High-Throughput Web Framework for Djazair

Kasbah is the official, enterprise-ready web application and REST API framework for the Djazair programming language. Engineered from the ground up for high concurrency, rock-solid security, expressive routing, and seamless developer experience.

Asynchronous High Speed

Native non-blocking HTTP dispatching capable of handling thousands of requests per second.

Enterprise Security

Pre-configured Helmet (8 security headers), strict CORS policies, and HMAC-signed sessions.

Expressive Routing

Flexible parameter matching, sub-router nesting, route groups, and multi-tier middleware pipelines.

Full-Stack MVC Ready

Integrated with Qalam AST template engine, multipart uploader, and fluent schema validation.

Quick Start Guide

Create your first production-grade HTTP web server in less than 30 seconds:

server.dz 
use kasbah

# 1. Initialize application
let app = new kasbah.app({
    "port": 3000,
    "host": "127.0.0.1"
})

# 2. Register basic route
app.get("/", fn(req, res)
    res.ok({"message": "Welcome to Kasbah on Djazair!"})
end)

# 3. Dynamic parameter route
app.get("/api/users/:id", fn(req, res)
    res.ok({
        "userId": req.param("id"),
        "clientIp": req.ip
    })
end)

# 4. Start server
app.listen()
Run with Djazair Compiler:
Execute djazair server.dz in your terminal. You'll see the ISO 8601 standardized startup log: 2026-09-07 20:00:00 [INFO] [Kasbah] Kasbah server starting on 127.0.0.1:3000.

 Route Groups & Sub-Routers

          
Group related routes by common URI prefixes and shared middleware pipelines:


          

            
 Route Groups with Group-Level Middleware

            
# Auth Guard Middleware
let requireAuth = fn(req, res)
    if req.token() == ""
        res.unauthorized("Authentication required")
    end
end

# Route Group with Prefix and Middleware
app.group("/api/v1", [requireAuth], fn(v1)
    v1.get("/profile", fn(req, res)
        res.ok({"user": "Riad"})
    end)

    # Nested Sub-Group
    v1.group("/admin", fn(admin)
        admin.get("/stats", fn(req, res)
            res.ok({"activeUsers": 1240})
        end)
    end)
end)

          


          

            

              
app.use(prefix, routerInstance)

              Sub-Router Mounting
            

            
Mounts a modular standalone new kasbah.router() instance under an application path prefix.

    # Read session
    let user = req.session.get("user", "Guest")

 Schema Validator Engine

          
Fluent schema validation rules with structured error reporting:


          

            
 Request Validation Example

            
app.post("/api/register", fn(req, res)
    let v = kasbah.validator(req.body, {
        "username": "required|min:3|max:20|alphanumeric",
        "email":    "required|email",
        "age":      "required|numeric|min:18",
        "role":     "required|in:trader,analyst,admin"
    })

    if v.fails()
        return res.validationError(v.errors())
    end

    let cleanData = v.validated()
    res.created({"status": "User registered", "data": cleanData})
end)

          


          

            

              
                

                  Validation Rule
                  Example
                  Constraint Description
                

              
              
                

                  required
                  "name": "required"
                  Field must exist and not be Null, False, or empty string.
                

                

                  email
                  "email": "required|email"
                  Field must match valid email syntax containing @ and domain.
                

                

                  min:N
                  "password": "min:8"
                  String length >= N characters, or numeric value >= N.
                

                

                  max:N
                  "bio": "max:500"
                  String length <= N characters, or numeric value <= N.
                

                

                  numeric
                  "amount": "numeric"
                  Field must be an integer or floating point number.
                

                

                  alpha
                  "firstName": "alpha"
                  Field must contain letters only (a-z, A-Z).
                

                

                  alphanumeric
                  "code": "alphanumeric"
                  Field must contain letters and digits only.
                

                

                  in:a,b,c
                  "role": "in:trader,admin"
                  Field value must match one of the allowed whitelist values.
                

                

                  regex:pattern
                  "sku": "regex:^[A-Z]{3}-[0-9]+$"
                  Field must match custom regular expression.

app.onNotFound(fn(req, res)

        "statusCode": 500,
        "message":    "${err}"
    })
end)

Encodes Unicode filenames according to RFC 5987 for safe attachment downloads.

          


          

            

              
kasbah.urlEncode(string) / kasbah.urlDecode(string)

              Helper
            

            
Percent-encodes or decodes arbitrary strings, query strings, and URL path components.

              Configuration

              Telemetry
