Djazair Raylib Extension

A high-performance, hardware-accelerated 2D game development and interactive multimedia framework for the Djazair Programming Language. Powered by Raylib 5.5 with native C-API integration, zero-overhead bindings, pure Object-Oriented APIs, and automatic Garbage Collector finalizers.

Hardware Accelerated (OpenGL 3.3+)
Dual OOP & Procedural Paradigms
Type-Safe & GC Memory Protection
Spatial Audio & Streaming Music
Pixel-Perfect Collision Detection

Quick Start & Installation

Import the Raylib extension in any Djazair script using the standard module resolution syntax.

Zero Configuration: The compiled raylib.dll is automatically discovered by the Djazair Virtual Machine through standard search paths (extensions/raylib).
main.dz — Hello Window Example 
use raylib as rl

# 1. Initialize 800x600 Window
let win = new rl.Window(800, 600, "Hello Djazair Game Engine!")
win.setFPS(60)

# 2. Main Game Loop
while win.isOpen()
    # Begin drawing frame
    win.begin()
    win.clear(rl.RAYWHITE)

    # Render graphics and text
    rl.drawText("Welcome to Djazair 2D Gaming!", 200, 240, 24, rl.DARKBLUE)
    rl.drawCircle(400, 360, 45.0, rl.RED)
    rl.drawText("FPS: " + str(win.getFPS()), 15, 15, 16, rl.DARKGRAY)

    # End drawing and swap backbuffers
    win.finish()
end

# 3. Clean exit
win.close()

Window Class & Game Loop Management

The Window class encapsulates window creation, lifecycle management, resizing, title handling, and frame-rate capping.

new Window(width: Int, height: Int, title: String)
OOP Class Native C

Initializes the desktop window and OpenGL rendering context with the specified dimensions.

ParameterTypeDescription
widthIntScreen width in pixels (e.g. 1280).
heightIntScreen height in pixels (e.g. 720).
titleStringWindow title bar text.
win.isOpen() -> Bool
OOP Method

Returns True while the window is active. Returns False when the user clicks the close button or presses ESC.

win.begin() / win.finish() -> Null
OOP Method

Marks the start and end of all drawing calls for the current frame. Swaps OpenGL framebuffers automatically on finish.

win.clear(color: Color | Array = [0, 0, 0, 255]) -> Null
OOP Method

Clears the backbuffer with the given background color before rendering objects.

win.setFPS(fps: Int) -> Null
OOP Method

Sets target frame rate (e.g. 60 or 144). Raylib will sleep between frames to maintain consistent timing.

win.getFPS() -> Int
OOP Method

Returns the real-time calculated frames per second as an exact Int.

Mathematics & Vector Types

Vector classes provide 2D and 3D vector arithmetic, scaling, normalization, and distance calculations.

Vector2 & Vector3 Usage in Djazair 
use raylib as rl

let pos = new rl.Vector2(100.0, 150.0)
let vel = new rl.Vector2(10.0, -5.0)

# Vector Arithmetic
let nextPos = pos.add(vel)              # (110.0, 145.0)
let scaledVel = vel.scale(2.0)          # (20.0, -10.0)
let speed = vel.length()                # 11.1803
let normalized = vel.normalize()        # (0.894, -0.447)
let dist = pos.distance(nextPos)        # Distance between points

Keyboard Input & Keycodes

Query continuous key states (holding) or single trigger events (press/release).

Keyboard Handling Example 
# Continuous movement while holding arrow keys
if rl.isKeyDown(rl.KEY_LEFT)   playerX -= 5.0 end
if rl.isKeyDown(rl.KEY_RIGHT)  playerX += 5.0 end
if rl.isKeyDown(rl.KEY_UP)     playerY -= 5.0 end
if rl.isKeyDown(rl.KEY_DOWN)   playerY += 5.0 end

# Single trigger event (Jump on spacebar)
if rl.isKeyPressed(rl.KEY_SPACE)
    jump()
end

# Quit game on Escape
if rl.isKeyPressed(rl.KEY_ESCAPE)
    win.close()
end

Camera 2D & Viewport Tracking

Camera2D provides 2D scrolling, zooming, rotation, and smooth player following, with screen-to-world coordinate transformations.

Camera2D Target Tracking Pattern 
use raylib as rl

let win = new rl.Window(1280, 720, "2D Camera World")
win.setFPS(60)

# Create Camera centered on screen
let cam = new rl.Camera2D(640.0, 360.0, 0.0, 0.0, 0.0, 1.0)
let playerX = 0.0
let playerY = 0.0

while win.isOpen()
    # Update Player & Follow with Camera
    if rl.isKeyDown(rl.KEY_D) playerX += 6.0 end
    if rl.isKeyDown(rl.KEY_A) playerX -= 6.0 end
    cam.target_x = playerX
    cam.target_y = playerY

    win.begin()
    win.clear(rl.DARKGRAY)

    # 1. World Space (Transformed by Camera)
    cam.begin()
        # Draw world tiles and player
        rl.drawRectangle(-500, -500, 1000, 1000, rl.GRAY)
        rl.drawCircle(playerX, playerY, 20.0, rl.GOLD)
    cam.finish()

    # 2. Screen Space (Fixed UI / HUD)
    rl.drawText("PLAYER X: " + str(int(playerX)), 20, 20, 18, rl.WHITE)
    rl.drawText("ZOOM: " + str(cam.zoom), 20, 45, 18, rl.WHITE)

    win.finish()
end

Textures & Sprite Sheets

Load PNG, JPG, BMP, and GIF images from disk into GPU VRAM. All Texture resources include automatic GC finalizers to prevent memory leaks.

Sprite Sheet Animation Example 
use raylib as rl

let win = new rl.Window(800, 600, "Sprite Animation")
win.setFPS(60)

# Load Texture (Relative path resolved automatically)
let heroTex = new rl.Texture("assets/hero_sheet.png")

let frameWidth = 64
let frameHeight = 64
let currentFrame = 0
let frameTimer = 0

while win.isOpen()
    frameTimer += 1
    if frameTimer >= 8
        frameTimer = 0
        currentFrame = (currentFrame + 1) % 4
    end

    win.begin()
    win.clear(rl.BLACK)

    # Draw specific sprite sheet crop (frame)
    heroTex.drawRec(currentFrame * frameWidth, 0, frameWidth, frameHeight, 360, 260, rl.WHITE)

    win.finish()
end

# Clean up texture VRAM (Optional: GC cleans automatically)
heroTex.unload()
win.close()

Audio Devices, Sounds & Music Streams

Raylib provides full audio device management, sound effects (WAV, OGG in-memory playback), and streaming background music (OGG, MP3).

Audio Playback & Streaming Music 
use raylib as rl

let win = new rl.Window(800, 600, "Audio Master")
let audio = new rl.Audio() # Initializes audio device

# Short Sound Effect (Loaded entirely into RAM)
let coinSound = new rl.Sound("assets/coin.wav")

# Background Music (Streamed from disk in chunks)
let bgm = new rl.Music("assets/theme.ogg")
bgm.play()
bgm.setVolume(0.6)

while win.isOpen()
    # Music stream buffer MUST be updated every frame in the loop!
    bgm.update()

    if rl.isKeyPressed(rl.KEY_SPACE)
        coinSound.play()
    end

    win.begin()
    win.clear(rl.DARKGRAY)
    rl.drawText("Press SPACE to play SFX", 260, 280, 20, rl.WHITE)
    win.finish()
end

# Clean unload
bgm.unload()
coinSound.unload()
audio.close()
win.close()
