High-Performance Desktop Applications for Djazair

Build blazing-fast, memory-efficient Windows desktop applications using modern web technologies (HTML5, CSS3, React, Vue, Svelte) powered by Microsoft Edge WebView2 and high-speed Win32 native C++ integration.

Edge Chromium Core

Modern HTML5/ESNext web standards backed by evergreen WebView2 runtime.

Ultra-Low Memory (<30MB)

Shares installed Windows runtime. 10x lighter than typical Electron builds.

Sub-Millisecond IPC

Direct asynchronous two-way message passing bridge between Djazair and JS.

Single-Instance Mutex

OS-level named mutex protection with automatic window activation on relaunch.

Native Dragging

Silky smooth client-area window dragging for custom frameless titlebars.

Attention Flashing

Win32 FlashWindowEx support to attract user attention on background tasks.

Overview & Architecture

The Djazair webview module provides full native desktop GUI capabilities to Djazair programs without bundling bloated browser runtimes.

Layer Technology Responsibility
High-Level Djazair API init.dz / application.dz / window.dz Object-Oriented classes (App, Window, Bridge, Menu, Tray, Notification).
Native C++ Extension webview_native.cc / Win32 Window creation, message pump, DWM dark mode, named mutexes, Win32 events, FlashWindowEx.
Rendering Engine Microsoft Edge WebView2 Hardware-accelerated web rendering, WebAssembly, modern DOM, DevTools, protocols.
Frontend Injected Bridge window.djazair Automatic JavaScript IPC bridge injected into every page context before scripts run.
Zero Installation Footprint: Windows 10 and 11 come with the Microsoft Edge WebView2 Runtime preinstalled as an OS component. Your distributed Djazair applications remain exceptionally compact and load instantaneously.

Quick Start Guide

Create and run your first modern desktop application in Djazair in less than 30 seconds.

Djazair — hello_world.dz 
use webview

# Initialize application window with HTML content
let app = webview.createWindow({
    "title": "Djazair Desktop Application",
    "width": 900,
    "height": 600,
    "center": True,
    "darkTitleBar": True,
    "singleInstance": True,
    "appId": "my.unique.djazair.app"
})

app.onReady(fn()
    app.window.setHtml("
        <html>
        <body style='background:#0f172a;color:#f8fafc;font-family:sans-serif;display:flex;align-items:center;justify-content:center;height:100vh;margin:0;'>
            <div style='text-align:center;'>
                <h1 style='font-size:36px;margin-bottom:8px;'>Hello from Djazair WebView! 🇩🇿</h1>
                <p style='color:#94a3b8;'>Powered by Edge WebView2 and Native Win32 C++</p>
            </div>
        </body>
        </html>
    ")
end)

# Start native Win32 message loop
app.run()

To execute the application, run:

Terminal 
djazair hello_world.dz

Application Lifecycle & Mutex

The App class manages the primary operating system message loop, window hierarchy, and single-instance mutex enforcement.

app.run() Core
Enters the native Win32 standard message pump (GetMessage / TranslateMessage / DispatchMessage). Blocks until the main window is closed or app.quit() is invoked.
app.quit() / app.close() Core
Gracefully closes all windows managed by the application, dispatches the onQuit handler, frees WebView2 environment controllers, and terminates the event loop.
app.isValid() → Boolean Core
Checks if the primary window handle is valid, open, and has not yet been destroyed.
app.onReady(callback) Lifecycle
Registers a callback function executed immediately before the event loop starts and after the primary window is established.
app.onQuit(callback) Lifecycle
Registers a callback invoked prior to process termination to save state, flush configuration files, or release resources.
app.onError(callback) Diagnostics
Registers a global handler receiving uncaught WebView2 native exceptions and initialization errors.
app.setDebug(enable) Diagnostics
Dynamically toggles developer mode, console forwarding, and F12 DevTools inspection.
app.createWindow(options = {}) → Window Multi-Window
Spawns a secondary native window managed under the same application event loop.
Single Instance Lock (singleInstance, appId) New Feature
Prevents multiple instances of your application from running simultaneously using a Win32 Named Mutex (Local\DjazairApp_<appId>). If a user attempts to launch a second instance, the existing instance is automatically brought to the foreground, restored if minimized, flashed in the taskbar, and the duplicate process terminates cleanly with exit code 0.
Djazair Example 
use webview

# Enforce a single running instance across the entire OS session
let app = webview.createWindow({
    "title": "Music Player Pro",
    "singleInstance": True,
    "appId": "com.djazair.musicplayer",
    "width": 1000,
    "height": 700
})

app.run()
app.requestSingleInstanceLock(appId) → Boolean Mutex
Low-level programmatic query attempting to acquire the Named Mutex lock for a specified application identifier. Returns True if this process is the primary owner.
app.focusExistingInstance(title) → Boolean Mutex
Finds an existing running window instance matching the caption title and restores, unminimizes, and focuses it in the foreground.

Frameless Windows & Native Dragging

Build modern apps with seamless custom titlebars (like Spotify, Discord, or VS Code) using native dragging.

window.startDragging() & window.djazair.startDragging() New Feature
Releases mouse capture and initiates a native Win32 window move loop (WM_NCLBUTTONDOWN with HTCAPTION). This allows any HTML element in your web frontend to act as a smooth, native window drag handle without lag or stutter.
HTML & CSS Titlebar 
<!-- Custom Draggable Titlebar -->
<div id="titlebar" style="height:34px;background:#1e1e2e;display:flex;align-items:center;justify-content:space-between;user-select:none;">
  <div style="padding-left:14px;color:#cdd6f4;font-size:12px;font-weight:600;">My Frameless App</div>
  
  <!-- Window Control Buttons -->
  <div style="display:flex;">
    <button id="btnMin" class="win-btn">−</button>
    <button id="btnMax" class="win-btn">□</button>
    <button id="btnClose" class="win-btn close">×</button>
  </div>
</div>
JavaScript — titlebar.js 
// Initiate native drag whenever the user drags the titlebar
document.getElementById('titlebar').addEventListener('mousedown', (e) => {
  // Ignore clicks on control buttons
  if (e.target.closest('button')) return;
  if (e.button === 0) { // Primary left click
    window.djazair.startDragging();
  }
});

// Window control buttons using Djazair IPC
document.getElementById('btnMin').addEventListener('click', () => window.djazair.invoke('win-minimize'));
document.getElementById('btnMax').addEventListener('click', () => window.djazair.invoke('win-maximize'));
document.getElementById('btnClose').addEventListener('click', () => window.djazair.invoke('win-close'));
Djazair — main.dz 
use webview

let app = webview.createWindow({
    "title": "Custom App",
    "frameless": True,
    "width": 900,
    "height": 600
})

# Wire up window control events sent from JavaScript
app.bridge.on("win-minimize", fn(_)
    app.window.minimize()
    return True
end)

app.bridge.on("win-maximize", fn(_)
    if app.window.isMaximized()
        app.window.restore()
    else
        app.window.maximize()
    end
    return True
end)

app.bridge.on("win-close", fn(_)
    app.quit()
    return True
end)

app.run()

Two-Way IPC Architecture

Seamlessly communicate between your Djazair backend code and your HTML/JavaScript frontend via low-latency asynchronous JSON message passing.

Djazair Backend IPC 
use webview

let app = webview.createWindow({ "title": "IPC Demo" })

# Handle invoke requests from JavaScript and return results
app.bridge.on("getUserProfile", fn(payload)
    let userId = payload["id"]
    return {
        "id": userId,
        "name": "Riyadh Harizi",
        "role": "Lead Architect",
        "skills": ["Djazair", "C++", "WebView2"]
    }
end)

# Expose direct binding callable on window
app.bridge.expose("nativeCalculator", fn(args)
    return args[0] * args[1]
end)

# Push events to JavaScript
app.onReady(fn()
    app.bridge.send("system-status", { "online": True, "ping": 12 })
end)

app.run()
JavaScript Frontend IPC 
// Listen for push events sent from Djazair
window.djazair.on('system-status', (status) => {
  console.log('System online:', status.online, 'Ping:', status.ping);
});

// Request data from Djazair using Promises
async function loadUser() {
  try {
    const user = await window.djazair.invoke('getUserProfile', { id: 101 });
    console.log('Loaded user:', user.name, user.role);
    document.getElementById('userName').innerText = user.name;
  } catch (err) {
    console.error('Failed to load user:', err);
  }
}
JavaScript — RPC Invocation 
// Frontend JS — Invoke backend and await JSON response
async function getCalculation() {
  try {
    const response = await window.djazair.invoke('calculateSum', { a: 15, b: 27 });
    console.log('Calculation Result:', response.result); // 42
  } catch (err) {
    console.error('Calculation error:', err);
  }
}

Bridge Methods (`app.bridge`)

Method Signature Description
on bridge.on(channel, handler) Registers a callback function handling incoming invoke messages from JS.
send bridge.send(channel, data) Pushes an asynchronous event and JSON payload to JavaScript.
invoke bridge.invoke(jsCode) Evaluates an expression in JavaScript and emits the result.
expose bridge.expose(name, handler) Exposes a native Djazair function directly as window[name] in JS.

The window.djazair Global Object

Every web page rendered in Djazair automatically has access to the window.djazair bridge:

Method Signature Description
invoke invoke(channel, payload) → Promise<any> Calls a Djazair backend handler and returns a Promise with the auto-deserialized return value.
on on(channel, callback) Subscribes a listener function to push events dispatched from app.bridge.send().
off off(channel [, callback]) Unsubscribes a specific listener or all listeners from an event channel.
startDragging startDragging() Initiates native Win32 window dragging from an HTML/CSS titlebar on mousedown.

Step-by-Step Guide: Modern Frameless App

Assemble a commercial-grade, borderless application using single-instance locking, native dragging, and bidirectional IPC.

Production Architecture: This blueprint demonstrates the recommended pattern for desktop applications built with Djazair.
Djazair — app.dz 
use webview

# 1. Initialize Single-Instance Frameless Window
let app = webview.createWindow({
    "title": "Modern Studio Pro",
    "width": 1100,
    "height": 750,
    "frameless": True,
    "singleInstance": True,
    "appId": "com.studio.pro",
    "backgroundColor": "#0f172a"
})

# 2. Wire Window Control Endpoints
app.bridge.on("win-minimize", fn(_)
    app.window.minimize()
    return True
end)

app.bridge.on("win-maximize", fn(_)
    if app.window.isMaximized()
        app.window.restore()
    else
        app.window.maximize()
    end
    return True
end)

app.bridge.on("win-close", fn(_)
    app.quit()
    return True
end)

# 3. Flash taskbar if background task finishes while window is not focused
app.bridge.on("longTaskFinished", fn(_)
    if not app.window.isFocused()
        app.window.flash(True)
    end
    return True
end)

# 4. Load page content & start event loop
app.onReady(fn()
    app.window.navigate("index.html")
end)

app.run()

Deployment & Troubleshooting

Tips for troubleshooting, remote debugging, and ensuring seamless deployment.

Requirement / Challenge Recommended Solution
Inspect HTML/CSS/Console Set "debug": True in createWindow and press F12 or right-click → Inspect.
Prevent White Flash on Launch Set "backgroundColor": "#0f172a" to match your web app's background CSS.
Isolate User Profile / Cookies Set custom "userDataDir": "./app_data" to separate cache, localStorage, and session data.
Prevent Multiple Running Instances Set "singleInstance": True and a unique "appId": "com.company.myapp".
Seamless Dragging for Custom Titlebars Attach onmousedown="window.djazair.startDragging()" to the titlebar element.
Zoom Scaling on High-DPI Displays Use window.setZoomLevel(1.25) and query screen constraints with window.getScreenSize().
Custom Protocol Asset Security Register internal protocol handler via webview.protocolRegister().
