Official Djazair Bundler

Djazair dpack Bundler

Package your Djazair scripts (.dz) and all their dependencies—including the native interpreter, standard libraries, extensions, and assets—into a single, self-contained executable file (.exe on Windows or native binary on Linux). Distribute without requiring any runtime installation!

Get Started Interactive Config Studio API Reference

Self-Contained Executables

Embeds the Djazair interpreter, prelude, and standard libraries inside the executable binary with instant subsequent launches.

Smart Dependency Scanning

Automatically scans your code for use <module> statements and bundles external extensions (e.g. webview, raylib, kasbah) without extra configuration.

Seamless GUI Focus

Automatically grants foreground window rights (AllowSetForegroundWindow) on Windows to ensure GUI apps restore and focus properly from system tray.

Source Obfuscation

Optional XOR scrambling protects your raw source code from standard zip extraction and casual inspection.

Quick Start Guide

Create a standalone executable in two lines of Djazair code.

Djazair (build.dz) 
use dpack

# Compile app.dz into app.exe (automatically bundles assets and dependencies)
dpack.pack("app.dz")

Run the build script from your terminal:

Shell 
djazair build.dz

Core API Reference

Detailed specification of all methods exported by the dpack extension.

dpack.pack(scriptPath = Null, outputPath = Null, options = {})
Primary API

Packages a Djazair entry script into a standalone executable. If scriptPath is omitted, dpack automatically loads the main script specified in dpack.json.

Parameter Type Default Description
scriptPath String | Null Null The entry script path (e.g. "main.dz"). If Null, resolved from dpack.json.
outputPath String | Null Null Target executable path. If Null, defaults to script basename with .exe on Windows.
options Dictionary {} Configuration dictionary overriding dpack.json settings.
Djazair 
use dpack

dpack.pack("src/main.dz", "dist/MyApp.exe", {
    "console": False,
    "portable": True,
    "encrypt": True,
    "assets": ["ui/", "audio/"]
})
dpack.verify(exePath) → Bool
v1.0.2

Inspects the binary trailer of the specified executable to verify whether it contains a valid dpack payload and matching footer signature.

Djazair 
use dpack

if dpack.verify("dist/MyApp.exe")
    print("Executable is a verified dpack standalone bundle.")
else
    print("Not a valid dpack bundle.")
end
dpack.inspect(exePath) → Array<Dictionary>
v1.0.2

Extracts and returns the manifest of all files bundled inside a packed executable (including path, compressed size, and attributes) without executing the application.

Djazair 
use dpack

let files = dpack.inspect("dist/MyApp.exe")
for item in files
    print("File: ${item[\"path\"]} - ${item[\"size\"]} bytes")
end
dpack.cleanCache()

Purges old cached build staging folders and temporary runtime caches from %TEMP% (Windows) or /tmp (Linux) to reclaim disk space.

Djazair 
use dpack

# Frees disk space by removing old cached dpack runs
dpack.cleanCache()

Configuration & Options

Configure your builds with declarative dpack.json files or options dictionaries.

Zero Configuration: If a dpack.json file exists in the directory where dpack.pack() is invoked, its options are automatically loaded and applied.
Key Type Default Description
main String "main.dz" Entry script to package.
output String Null Destination binary path.
console Bool True Set to False to hide the console terminal window for GUI applications.
portable Bool False If True, places the cache folder next to the .exe rather than in %TEMP%.
encrypt Bool False Enables XOR source obfuscation for bundled .dz scripts.
assets Bool | Array True True auto-bundles directory assets; False excludes assets; Array specifies exact assets.
extensions Array [] Explicit list of extensions to force-include if dynamically loaded.
quiet Bool False Suppresses build progress output.

Runtime Architecture & Foreground Focus

How dpack executes bundled applications and manages Windows desktop integration.

Foreground Window Focus in v1.0.2:
On Windows, background and spawned processes are subject to focus-stealing prevention. In dpack v1.0.2, the native stub calls AllowSetForegroundWindow(pi.dwProcessId) immediately upon spawning the child interpreter. This ensures that GUI applications (e.g. WebView, Qt, Raylib) can reliably take focus, activate, and restore their windows from the system tray when clicked!
Security Boundary Notice:
The encrypt / protect option provides source code obfuscation against casual inspection. Because the stub must decrypt files at runtime to execute them, decrypted scripts reside in the cache folder. Never store confidential passwords or API private keys in bundled code!
