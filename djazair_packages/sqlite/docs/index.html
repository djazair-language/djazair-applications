Embedded Relational Database for Djazair

A zero-configuration, self-contained, ACID-compliant SQLite 3 engine for the Djazair Programming Language. Features safe parameterized queries, automatic script directory path resolution, associative mapping, transactions, and a high-performance native C dynamic bridge.

SQL Injection Safe

Built-in parameterized safeQuery & safeExecute with C-level escaping.

Native C Speed

Direct Win32/POSIX C binding via sqlite3.h and Djazair VM Resource management.

Full ACID Transactions

Strict commit and rollback mechanics with try/catch/finally safety patterns.

Smart Path Resolution

Auto-resolves paths relative to current script directory with seamless :memory: support.

Quick Start Guide

Get started with SQLite in Djazair in less than 60 seconds: open an embedded database, create a table, insert parameterized rows, and query data using associative maps.

quickstart.dz 
use sqlite

# 1. Connect to a local database file (creates it if missing)
let db = sqlite.connect("app.db")

if db.isConnected()
    # 2. Execute table creation DDL
    db.execute("CREATE TABLE IF NOT EXISTS users (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        name TEXT NOT NULL,
        email TEXT UNIQUE,
        score REAL
    )")

    # 3. Insert records safely using parameterized queries (? placeholders)
    db.safeExecute("INSERT OR IGNORE INTO users (name, email, score) VALUES (?, ?, ?)", 
                   ["Harizi Riyadh", "harizi@djazair.org", 99.5])
    db.safeExecute("INSERT OR IGNORE INTO users (name, email, score) VALUES (?, ?, ?)", 
                   ["Anis Benali", "anis@example.dz", 88.0])

    print("Rows modified: " + str(db.changes()))
    print("Last inserted row ID: " + str(db.insertId()))

    # 4. Query records with type-safe parameters
    let res = db.safeQuery("SELECT * FROM users WHERE score > ? ORDER BY score DESC", [90.0])

    if !isNull(res)
        print("Column names: " + str(res.columns()))

        # 5. Fetch all rows as an array of associative maps (dictionary)
        let users = res.fetchAllAssoc()
        for user in users
            print("User #" + str(user["id"]) + " -> " + user["name"] + " (" + str(user["score"]) + " pts)")
        end

        # Always close result sets when done
        res.close()
    end

    # 6. Close database connection
    db.close()
    print("Database operation finished successfully.")
else
    print("Database connection failed: " + db.error())
end
In-Memory Databases: You can pass ":memory:" to sqlite.connect(":memory:") to create an ultra-fast temporary database that lives entirely in RAM and vanishes when the connection is closed.

Connection Class API Reference

The Connection class represents an active SQLite database handle. It provides methods for executing DDL/DML, running parameterized queries, managing transactions, and querying metadata.

sqlite.connect(path: String) → Connection
Factory Path Resolver

Instantiates a new Connection object and opens the SQLite database. If a relative path is passed (e.g. "data.db" or "db/app.sqlite"), it automatically resolves it relative to the directory of the running .dz script via process.scriptDir(). Supports ":memory:" for RAM-only databases.

path (String): Filepath to the database or ":memory:".
Djazair Example 
use sqlite

# Relative to current script
let db1 = sqlite.connect("analytics.db")

# In-memory transient database
let db2 = sqlite.connect(":memory:")

# Absolute path
let db3 = sqlite.connect("C:/Database/enterprise.db")
Connection.isConnected() → Bool
Status

Returns True if the database handle is currently open and valid, or False if opening failed or the connection has already been closed.

Djazair Example 
use sqlite

let db = sqlite.connect("data.db")
if db.isConnected()
    print("Database connected successfully!")
    db.close()
else
    throw "Database connection failed: " + db.error()
end
Connection.close() → Null
Lifecycle

Closes the underlying SQLite 3 database handle, releasing all file locks, B-tree caches, and memory structures. Sets connected = False. Safe to call multiple times (idempotent).

Djazair Example 
use sqlite

let db = sqlite.connect(":memory:")
print("Connected before close? " + str(db.isConnected())) # True
db.close()
print("Connected after close? " + str(db.isConnected()))  # False
Connection.error() → String
Diagnostics

Returns the latest error message reported by the SQLite engine for this connection via sqlite3_errmsg(). If the connection is not open, returns "Database not open".

Djazair Example 
use sqlite

let db = sqlite.connect(":memory:")
let ok = db.execute("MALFORMED SQL SYNTAX")
if !ok
    print("SQLite Error: " + db.error()) # e.g. "near \"MALFORMED\": syntax error"
end
db.close()
Connection.raw() → Resource
Hybrid

Returns the raw VM Resource pointer wrapping the native sqlite3* pointer. Intended for advanced hybrid scenarios or custom native C extension interoperability.

Connection.libversion() → String
Information Module Function

Returns the version string of the linked SQLite C runtime engine (e.g. "3.51.1"). Also accessible at the library root as sqlite.libversion().

Djazair Example 
use sqlite

print("SQLite Engine: " + sqlite.libversion())

let db = sqlite.connect(":memory:")
print("Connection SQLite Version: " + db.libversion())
db.close()

Statement Execution API Reference

Methods to run DDL, non-returning DML commands (INSERT, UPDATE, DELETE), and query execution (SELECT). Includes parameter binding protection against SQL injection attacks.

Connection.execute(sql: String) → Bool
DDL / DML

Compiles and immediately steps through an arbitrary SQL statement. Suitable for CREATE TABLE, DROP TABLE, PRAGMA, INSERT, UPDATE, and DELETE. Automatically prepares, steps, and finalizes the statement. Returns True on success (when step returns SQLITE_DONE or SQLITE_ROW), or False on failure.

sql (String): Raw SQL string to execute. Validated via assert.string.
Djazair Example 
use sqlite

let db = sqlite.connect("app.db")
let ok = db.execute("CREATE TABLE IF NOT EXISTS settings (key TEXT PRIMARY KEY, value TEXT)")
if ok
    print("Table ready!")
end
db.close()
Connection.safeExecute(sql: String, params: Array = []) → Bool
Injection Safe Recommended

The recommended way to execute write statements with dynamic user input. Safely replaces positional ? placeholders with escaped parameters via SQLite's native sqlite3_mprintf("%q") escaping engine. Correctly formats Null, numbers, and strings.

sql (String): SQL query with ? positional placeholders.
params (Array): Ordered array of values (Strings, Numbers, Null) to substitute.
Djazair Example 
use sqlite

let db = sqlite.connect("app.db")
db.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT, score REAL, bio TEXT)")

# Secure execution with user-provided parameters
let username = "O'Connor" # Contains single quote that would break raw SQL
let score = 94.2
let bio = Null

db.safeExecute("INSERT INTO users (name, score, bio) VALUES (?, ?, ?)", [username, score, bio])
print("Rows inserted: " + str(db.changes()))
db.close()
Connection.query(sql: String) → ResultSet | Null
SELECT

Prepares a SQL query (typically a SELECT) and returns an instance of ResultSet ready for fetching rows. If preparation fails (syntax error, unknown table, etc.), returns Null and error details can be retrieved via db.error().

sql (String): Query to prepare.
Djazair Example 
use sqlite

let db = sqlite.connect("app.db")
db.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT)")
db.safeExecute("INSERT OR IGNORE INTO users (id, name) VALUES (1, 'Riad')", [])

let res = db.query("SELECT id, name FROM users")
if !isNull(res)
    let rows = res.fetchAllAssoc()
    print("Found " + str(rows.length()) + " users.")
    res.close()
end
db.close()
Connection.safeQuery(sql: String, params: Array = []) → ResultSet | Null
Injection Safe Recommended

Safely prepares a read query containing ? placeholders, automatically escaping all parameter values against SQL injection attacks. Returns a ResultSet on success or Null on failure.

sql (String): Parameterized SQL query.
params (Array): Ordered parameters to bind.
Djazair Example 
use sqlite

let db = sqlite.connect("app.db")
db.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT, email TEXT)")
db.safeExecute("INSERT OR IGNORE INTO users (id, name, email) VALUES (1, 'Riad Harizi', 'harizi@djazair.org')", [])

let searchEmail = "harizi@djazair.org"
let res = db.safeQuery("SELECT * FROM users WHERE email = ? LIMIT 1", [searchEmail])

if !isNull(res)
    let user = res.fetchAssoc()
    if !isNull(user)
        print("Welcome back, " + user["name"] + "!")
    end
    res.close()
end
db.close()
Connection.insertId() → Number
Metadata

Returns the rowid of the most recent successful INSERT performed on this database connection (maps to native sqlite3_last_insert_rowid()). If no insert has occurred or the connection is closed, returns 0.

Connection.changes() → Number
Metadata

Returns the number of database rows that were modified, inserted, or deleted by the most recently completed INSERT, UPDATE, or DELETE statement (maps to native sqlite3_changes()).

Connection.escape(val: String | Number) → String
Utility

Escapes single quotes and special characters in strings or numbers using SQLite's internal sqlite3_mprintf("%q"). Throws a TypeError if an unsupported type is supplied.

ResultSet Class API Reference

The ResultSet class encapsulates an active cursor over query results. It allows retrieving rows sequentially as indexed arrays, associative maps, or in batch, as well as accessing column metadata.

ResultSet.fetchRow() → Array | Null
Cursor

Advances the statement cursor by calling sqlite3_step(). If a row is available (returns SQLITE_ROW), it extracts all column values into a zero-indexed Djazair Array (e.g. [1, "Riad", 98.5]). If the end of the result set is reached (or on error), returns Null.

Djazair Example 
use sqlite

let db = sqlite.connect("app.db")
db.execute("CREATE TABLE IF NOT EXISTS products (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT, price REAL)")
db.safeExecute("INSERT OR IGNORE INTO products (id, name, price) VALUES (1, 'Mechanical Keyboard', 89.99)", [])

let res = db.query("SELECT id, name, price FROM products")
if !isNull(res)
    let row = res.fetchRow()
    while !isNull(row)
        print("ID: " + str(row[0]) + ", Name: " + row[1] + ", Price: $" + str(row[2]))
        row = res.fetchRow()
    end
    res.close()
end
db.close()
ResultSet.fetchAssoc() → Map | Null
Cursor Recommended

Advances the statement cursor and returns the next row as a Djazair associative Map (key/value pairs), where keys correspond to the column names (or SQL aliases) and values correspond to the column data. Returns Null when no more rows exist.

Djazair Example 
use sqlite

let db = sqlite.connect("app.db")
db.execute("CREATE TABLE IF NOT EXISTS products (id INTEGER PRIMARY KEY AUTOINCREMENT, name TEXT, price REAL)")
db.safeExecute("INSERT OR IGNORE INTO products (id, name, price) VALUES (1, 'Mechanical Keyboard', 89.99)", [])

let res = db.query("SELECT id, name, price FROM products")
if !isNull(res)
    let prod = res.fetchAssoc()
    while !isNull(prod)
        print(prod["name"] + " costs $" + str(prod["price"]))
        prod = res.fetchAssoc()
    end
    res.close()
end
db.close()
ResultSet.fetchAllAssoc() → Array<Map>
Batch

Convenience method that loops through the entire result set, collecting all rows into an Array of associative Maps. Returns an empty array [] if the query yielded no rows.

Djazair Example 
use sqlite

let db = sqlite.connect("app.db")
db.execute("CREATE TABLE IF NOT EXISTS users (id INTEGER PRIMARY KEY AUTOINCREMENT, email TEXT)")
db.safeExecute("INSERT OR IGNORE INTO users (id, email) VALUES (1, 'developer@djazair.dz')", [])

let res = db.query("SELECT * FROM users")
if !isNull(res)
    let allUsers = res.fetchAllAssoc()
    for user in allUsers
        print(user["email"])
    end
    res.close()
end
db.close()
ResultSet.columns() → Array<String>
Metadata

Returns an array of strings containing the column names or aliases of the query. Internally caches the column names on first access to maximize loop performance.

ResultSet.close() → Null
Cleanup

Explicitly finalizes the underlying SQLite statement (calling sqlite3_finalize()) and frees native memory. Always call close() when finished processing results to avoid resource leaks and locked database tables.

Constants & Return Codes

Standard SQLite return codes exposed at the module level for cursor stepping, flow control, and low-level inspection.

sqlite.SQLITE_ROW = 100
Constant Integer

Returned by the native step() operation when another row of data is ready to be read via fetchRow() or fetchAssoc().

sqlite.SQLITE_DONE = 101
Constant Integer

Returned by step() when execution has finished successfully (e.g. an INSERT/UPDATE statement completed, or a SELECT cursor has exhausted all available rows).

Constant Value Source Meaning
sqlite.SQLITE_ROW 100 sqlite3.h Another row of data is ready for retrieval.
sqlite.SQLITE_DONE 101 sqlite3.h Statement execution has concluded (no further rows).

ACID Transactions & Concurrency

SQLite provides full ACID (Atomicity, Consistency, Isolation, Durability) transactions. The Djazair extension exposes manual transaction controls and robust patterns with try/catch/finally.

Method SQL Generated Description
db.beginTransaction() BEGIN TRANSACTION Opens a new transaction block. Subsequent writes are buffered until commit.
db.commit() COMMIT Persists all staged modifications atomically to disk.
db.rollback() ROLLBACK Aborts the transaction, reverting all modifications made since BEGIN.

The Robust Transaction Pattern in Djazair

Always wrap transactional code in a try / catch block so that any runtime exception or SQL failure automatically triggers a rollback():

Djazair — Bank Transfer Recipe 
use sqlite

let db = sqlite.connect("bank.db")
db.execute("CREATE TABLE IF NOT EXISTS accounts (id INTEGER PRIMARY KEY, balance REAL)")
db.safeExecute("INSERT OR IGNORE INTO accounts VALUES (101, 1000.0)", [])
db.safeExecute("INSERT OR IGNORE INTO accounts VALUES (102, 500.0)", [])

fn transferMoney(db, senderId, receiverId, amount)
    db.beginTransaction()
    try
        # 1. Deduct from sender
        let ok1 = db.safeExecute("UPDATE accounts SET balance = balance - ? WHERE id = ?", [amount, senderId])
        if !ok1 throw "Failed to deduct funds" end

        # 2. Add to receiver
        let ok2 = db.safeExecute("UPDATE accounts SET balance = balance + ? WHERE id = ?", [amount, receiverId])
        if !ok2 throw "Failed to deposit funds" end

        # 3. Commit changes atomically
        db.commit()
        print("Transfer completed successfully!")
        return True
    catch err
        # On any error, roll back completely
        db.rollback()
        print("Transfer failed and was rolled back: " + str(err))
        return False
    end
end

transferMoney(db, 101, 102, 250.0)
db.close()

SQL Injection Defense & Type Mapping

SQL Injection is one of the most critical security vulnerabilities. Djazair SQLite provides full parameterization via safeQuery() and safeExecute() to ensure query safety.

VULNERABLE PATTERN — DO NOT USE:
let sql = "SELECT * FROM users WHERE user = '" + input + "'"
If input is admin' --, an attacker bypasses authentication and gains administrative control of your database!
SECURE PATTERN — ALWAYS USE:
let res = db.safeQuery("SELECT * FROM users WHERE user = ?", [input])
Djazair automatically escapes strings and formats numbers, making SQL injection impossible.

Type Mapping Matrix

SQLite C Datatype Djazair Value Type Conversion Behavior
SQLITE_INTEGER Number Converted via sqlite3_column_int64() to double precision number.
SQLITE_FLOAT Number Converted via sqlite3_column_double() to double precision float.
SQLITE_TEXT String Allocated via djazair_str() with complete UTF-8 encoding support.
SQLITE_NULL Null Represented directly as Djazair's native Null.

Native C Dynamic Layer (_sqlite)

The low-level C extension is loaded via __dynamic("sqlite") and compiled using standard C99 against djazair_api.h. The functions below form the foundation of the high-level Djazair wrapper classes.

C Exported Function Arity C Source File Description
_s.open(path) 1 src/sqlite_db.c Calls sqlite3_open() and returns a SQLiteDB resource handle.
_s.close(db) 1 src/sqlite_db.c Calls sqlite3_close() and nullifies resource pointer.
_s.error(db) 1 src/sqlite_db.c Returns sqlite3_errmsg(db) as a Djazair string.
_s.prepare(db, sql) 2 src/sqlite_stmt.c Calls sqlite3_prepare_v2() and returns a SQLiteStmt resource.
_s.step(stmt) 1 src/sqlite_stmt.c Steps through the statement, returning status integer (100 for ROW, 101 for DONE).
_s.fetchRow(stmt) 1 src/sqlite_stmt.c Fetches current row with GC protection (djazair_push / djazair_pop).
_s.columnNames(stmt) 1 src/sqlite_stmt.c Returns array of column name strings via sqlite3_column_name().
_s.finalize(stmt) 1 src/sqlite_stmt.c Calls sqlite3_finalize() and clears statement pointer.
_s.insertId(db) 1 src/sqlite_db.c Returns sqlite3_last_insert_rowid(db).
_s.changes(db) 1 src/sqlite_db.c Returns sqlite3_changes(db).
_s.escape(str) 1 src/sqlite_db.c Calls sqlite3_mprintf("%q") and returns safely escaped string.
_s.libversion() 0 src/sqlite_db.c Returns the SQLite library version string (e.g. "3.45.1").
Garbage Collection Protection: In sqlite_stmt.c, newly allocated array objects are protected from GC reclamation during row extraction using djazair_push(vm, arr) and djazair_pop(vm).

Production Recipes & Design Patterns

Ready-to-use architectural patterns for building real-world enterprise applications with Djazair SQLite.

1. Object-Oriented Repository Pattern

Djazair — user_repository.dz 
use sqlite

class UserRepository
    init(db)
        self.db = db
        self.createTable()
    end

    createTable()
        self.db.execute("CREATE TABLE IF NOT EXISTS users (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            username TEXT UNIQUE NOT NULL,
            email TEXT UNIQUE NOT NULL,
            active INTEGER DEFAULT 1
        )")
    end

    create(username, email)
        let ok = self.db.safeExecute("INSERT OR REPLACE INTO users (username, email) VALUES (?, ?)", [username, email])
        if !ok return 0 end
        return self.db.insertId()
    end

    findById(id)
        let res = self.db.safeQuery("SELECT * FROM users WHERE id = ? LIMIT 1", [id])
        if isNull(res) return Null end
        let user = res.fetchAssoc()
        res.close()
        return user
    end

    findAll()
        let res = self.db.query("SELECT * FROM users ORDER BY id ASC")
        if isNull(res) return [] end
        let users = res.fetchAllAssoc()
        res.close()
        return users
    end

    delete(id)
        return self.db.safeExecute("DELETE FROM users WHERE id = ?", [id])
    end
end

let db = sqlite.connect("app.db")
let repo = new UserRepository(db)

let newId = repo.create("harizi", "harizi@djazair.dz")
let user = repo.findById(newId)
if !isNull(user)
    print("Found: " + user["username"])
end
db.close()

2. Schema Migrations & Version Tracking

Djazair — migrations.dz 
use sqlite

fn runMigrations(db)
    # 1. Create migration history table
    db.execute("CREATE TABLE IF NOT EXISTS _migrations (
        version INTEGER PRIMARY KEY,
        applied_at TEXT
    )")

    # 2. Check current version
    let currentVersion = 0
    let res = db.query("SELECT MAX(version) as ver FROM _migrations")
    if !isNull(res)
        let row = res.fetchAssoc()
        if !isNull(row) and !isNull(row["ver"])
            currentVersion = int(row["ver"])
        end
        res.close()
    end

    print("Current schema version: " + str(currentVersion))

    # Migration 1
    if currentVersion < 1
        db.beginTransaction()
        db.execute("CREATE TABLE products (id INTEGER PRIMARY KEY, title TEXT, price REAL)")
        db.safeExecute("INSERT INTO _migrations (version, applied_at) VALUES (1, '2026-09-07')", [])
        db.commit()
        print("Applied migration 1: products table created.")
    end

    # Migration 2
    if currentVersion < 2
        db.beginTransaction()
        db.execute("ALTER TABLE products ADD COLUMN stock INTEGER DEFAULT 0")
        db.safeExecute("INSERT INTO _migrations (version, applied_at) VALUES (2, '2026-09-07')", [])
        db.commit()
        print("Applied migration 2: stock column added.")
    end
end

let db = sqlite.connect("store.db")
runMigrations(db)
db.close()

3. Storing and Reading JSON Data with std/json

Djazair — json_storage.dz 
use sqlite
use json

let db = sqlite.connect("metadata.db")
db.execute("CREATE TABLE IF NOT EXISTS events (id INTEGER PRIMARY KEY, payload TEXT)")

# Serialize dictionary to JSON string
let eventData = { "type": "USER_SIGNUP", "userId": 42, "features": ["auth", "billing"] }
let encodedJson = json.encode(eventData)

# Insert safely as TEXT
db.safeExecute("INSERT INTO events (payload) VALUES (?)", [encodedJson])

# Read and deserialize back to native map
let res = db.query("SELECT payload FROM events ORDER BY id DESC LIMIT 1")
if !isNull(res)
    let row = res.fetchAssoc()
    let decoded = json.decode(row["payload"])
    print("Event Type: " + decoded["type"])
    print("User ID: " + str(decoded["userId"]))
    res.close()
end

db.close()

4. Production Performance PRAGMAs (WAL Mode)

Configure SQLite for maximum concurrency and high read/write throughput using standard PRAGMA statements:

Djazair — pragmas.dz 
use sqlite

let db = sqlite.connect("high_performance.db")

if db.isConnected()
    # 1. Write-Ahead Logging allows simultaneous readers and writers
    db.execute("PRAGMA journal_mode = WAL;")

    # 2. Synchronous NORMAL maintains ACID durability with maximum speed in WAL mode
    db.execute("PRAGMA synchronous = NORMAL;")

    # 3. Increase cache size (e.g. 64MB)
    db.execute("PRAGMA cache_size = -64000;")

    # 4. Wait up to 5000ms if database is temporarily locked
    db.execute("PRAGMA busy_timeout = 5000;")

    # 5. Store temp tables in RAM
    db.execute("PRAGMA temp_store = MEMORY;")

    print("High-performance database PRAGMAs configured.")
    db.close()
end

Common Errors and Fixes

Error Message Underlying Cause Resolution
database is locked Another thread/process holds an exclusive write lock, or an unclosed ResultSet cursor is active. Set PRAGMA busy_timeout = 5000; and ensure every ResultSet calls res.close().
no such table: [name] Table has not been created yet, or database path resolved to an unexpected location. Use CREATE TABLE IF NOT EXISTS or check resolved file path with path.resolve().
cannot start a transaction within a transaction Called beginTransaction() when a transaction is already in progress. Always pair beginTransaction() with either commit() or rollback().
Database not open Invoked query/execute on a connection after calling close() or after connection failed. Verify db.isConnected() before executing statements.
