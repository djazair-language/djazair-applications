# تطبيق التحكم بحواسيب الأطفال (Kids Control)

تم بناء هذا التطبيق باستخدام لغة **Djazair Programming Language** لتمكين الآباء من مراقبة والتحكم بحواسيب أبنائهم عن بعد عبر الشبكة المحلية (Local Network).

## الملفات
- `parent_app.dz`: تطبيق الآباء (لوحة التحكم)، يحتوي على واجهة رسومية باستخدام `webview`.
- `child_app.dz`: تطبيق الأبناء (الخدمة الخلفية)، يعمل كخادم يستقبل الأوامر وينفذها.

## المتطلبات
- يجب أن يكون كلا الجهازين متصلين بنفس الشبكة.
- تشغيل تطبيق الابن في حاسوب الطفل ليقوم بفتح المنفذ (8888).

## طريقة التشغيل

### 1. في حاسوب الطفل
شغّل السكريبت التالي في الخلفية:
```bash
djazair child_app.dz
```

### 2. في حاسوب الأب
شغّل واجهة التحكم الرسومية:
```bash
djazair parent_app.dz
```

## الأوامر المدعومة
- **PING**: فحص الاتصال والتأكد من عمل حاسوب الطفل.
- **LOCK**: قفل شاشة حاسوب الطفل فوراً.
- **SHUTDOWN**: إيقاف تشغيل حاسوب الطفل.
- **MESSAGE**: إرسال رسالة تنبيه تظهر كإشعار في شاشة الطفل.

## معايير البرمجة المتبعة
تمت كتابة الكود وفق أعلى المعايير العالمية:
- **Clean Code**: أكواد نظيفة ومهيكلة بطريقة احترافية.
- **Comments**: تعليقات وظيفية واضحة تشرح الغرض من كل كتلة برمجية.
- **Error Handling**: معالجة الأخطاء (try/catch) لضمان عدم توقف التطبيق عند حدوث مشاكل في الشبكة.
- **Modularity**: فصل المهام والمسؤوليات (تطبيق العميل مقابل تطبيق الخادم).
