HOW IT WORKS File-based Session Middleware
1. Cookie

kasbah.sid=<32-char hex> — generated on first visit, httpOnly; sameSite=Lax

2. FileStore

Session data stored as os.tmpDir()/kasbah_sessions/<sid>.json

3. Auto-save

Session is persisted automatically after every request, empty sessions are deleted
