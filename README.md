Djazair is a modern scripting language equipped with a rich ecosystem of native libraries and extensions. This ecosystem allows developers to easily build a wide range of applications, including:
* **Interactive 2D & 3D Games** (via the Raylib extension)
* **Modern Desktop GUIs** (via the WebView shell extension)
* **Database Management Tools** (via SQLite and MySQL database connectors)
* **Networking & Web utilities** (via cURL and the DWeb framework)

This repository serves as a hub for various applications showcasing the language's capabilities.

---

## ⚡ How to Run

To execute any program in this repository, you must have the **Djazair Interpreter** installed on your system.

### 1. Prerequisites
Ensure that the package/extension required by the application is installed via **DPM (Djazair Package Manager)**:
```bash
# Example of installing a required extension
dpm install <extension_name>
dpm build <extension_name>
```

### 2. Launching the Program
Run the main script file of the application directly using the `djazair` command:
```bash
djazair <path_to_main_script>.dz
```
